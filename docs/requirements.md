# 宝石奇谭项目需求

## 核心流程

当喜欢宝石、手头有标本盒的 9 岁孩子想继续探索时，可以打开宝石冒险岛，选一个站点，读证据、回答两题，收下一枚可在刷新后找回的印章，并把新发现写进手记。

用户已明确选择 A「宝石冒险岛」，要求游戏比原来的三站更有挑战，至少包含 50 种可玩的宝石和观赏材料，并已选择在 GitHub Pages 公开访问。父母是陪伴者。历史访谈已确认年龄、界面和规模。孩子最近一次实际玩到哪里、哪些题让他觉得简单、是否用实物对照，仍需真实试玩确认。

现有做法是五章各十站。每站完成观察和两题后可收章，集齐当章十枚印章可开综合案件，五案完成可获得称号。图鉴和手记帮助回看证据和记录发现。以几分钟完成一个站点作为设计假设，实际用时待测。

## 验收标准

| 编号 | 前提与操作 | 可观察结果 | 方法 |
| --- | --- | --- | --- |
| A1 | 初次打开首页，进入五章路线并切换章节 | 每章可发现十个可打开的站点。首次进入能看清探索流程与案件门槛 | 全量数据检查，桌面与手机宽度抽样 |
| A2 | 打开白水晶，读证据，先答错再改对，继续完成第二题 | 能在原题重试和回看证据。两题答对后才能收章，成功反馈有下一步入口 | 浏览器走查，自动模拟穷举全路线 |
| A3 | 已收印章，误关另一个未完成的站点并刷新，随后重玩已完成站点 | 已领取印章仍在，未完成站点可重新进入，重复领取计数不增加。进行中的题目在重新打开后从头开始 | 浏览器和存储回归检查 |
| A4 | 集齐一章十枚印章，再完成案件两题 | 解锁前无法打开案件，完成后章节显示已解决。五案完成显示研究员称号 | 自动全岛通关，抽样核对界面 |
| A5 | 从白水晶领章页打开手记，写入一条样例并保存 | 宝石已选中，刷新后从「我的发现」可找到该条手记 | 本地浏览器走查 |
| A6 | 用已有的三站版存档或不能写入的浏览器打开游戏 | 已有印章保留，受阻时仍可游戏，界面如实提示进度能否保存 | 自动存储回归和提示检查 |
| A7 | 用键盘退出弹窗，或在手机宽度完成一次观察和答题 | 焦点回到刚进入的站点或对应入口。手机宽度下题目、答案和继续按钮可操作 | 真实浏览器键盘和窄屏走查 |
| A8 | 抽查站点资料和图片说明 | 每个条目有可核查的出处，照片的标本身份和许可有记录，示意图有清楚标记 | 结构检查与逐条人工复核 |
| A9 | 两个标签页用同一份存档，A 保存或删除手记，B 打开站点或提交早已打开的编辑窗 | 阅读操作保留 A 的修改。已经删除的手记不会因旧编辑重新出现，编辑文字仍可复制 | 双标签页回归样例 |

本轮优先补齐答题、领章、手记的交接和中断恢复。继续扩展题量、逐站追加实物照片、跨设备同步及更复杂的研究和设计工具，按真实使用反馈再安排。
