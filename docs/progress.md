## 实际验收

- **A1 / A4**。自动检查验证 50 个不同站点、110 道题、5 次案件解锁以及最终称号。桌面和窄屏均看到五章入口与未解锁案件。真实浏览器只抽测白水晶，全部案件由自动测试覆盖。
- **A2 / A3 / A5 / A7**。本地桌面从五章路线打开白水晶，故意答错后可重试，答完两题可领章。重玩计数仍为 2。领章页打开手记时预选白水晶，用样例文字保存，刷新后仍可在「我的发现」找到。390 像素宽的浏览器嵌入视口完成同一关，页面无横向溢出。Escape 关闭弹窗后焦点回白水晶入口，未完成退出后可从头重开，已领取印章仍在。手机真机触控待验。
- **A6 / A9**。独立回归保留三站版印章与旧手记。A 页保存后 B 页浏览不会丢手记，A 页删除后 B 页浏览或提交旧编辑不会恢复已删除手记，旧编辑文字可复制。模拟写入失败时明确提示，当前页还能找回并导出内容。严格同时的存储写入仍受浏览器机制限制。
- **A8**。50 条目和 8 张本地照片通过格式、文件与署名字段检查。红玉髓、绿玉髓、金绿猫眼和宝石珊瑚改用 [馆藏研究](https://resources.metmuseum.org/resources/metpublications/pdf/Etruscan_Art_in_The_Metropolitan_Museum.pdf)、[绿玉髓实测资料](https://my.gia.edu/gems-gemology/spring-2026-gemnews-new-chrysoprase-production-australia)、[光学效果资料](https://www.gia.edu/gia-news-research/optical-effects-phenomenal-cabochons)和[珊瑚饰品研究](https://www.mdpi.com/2075-163X/6/2/56)。全库逐条事实复核仍待完成。42 个条目标有图标，待根据孩子是否需要对照实物决定补图优先级。
- 本次验收使用合成手记和代表性站点。没有孩子实际试玩记录，也没有可比较的旧版耗时数据。

## 接手与发布

从 [需求](requirements.md) 和 [架构](architecture.md) 接手。运行 `npm run check` 可复核自动验收。本轮本地审核提交为 `5a79326`，对应的上线状态可从 [GitHub Actions](https://github.com/handsun85s/gemstone-tales/actions/workflows/pages.yml) 查询。后续每次迭代通过本地验收后立即推送，部署成功后核对公开站点。下一阶段优先用手机真机和标本盒观察孩子能否独立完成一个站点，再按发现的困难排定内容补图和资料复核。
