# 儿童 UI 与 UX Playground

制作日期：2026-11-03。目标用户：9 岁孩子；父母与孩子通过实际操作选择视觉与交互方向。

采用结果：用户已选择 A「宝石冒险岛」，该方向已接入正式首页、图鉴、任务、手记与弹层。以下四套仍作为设计比较原型保留。正式版印章单独持久保存于 `gemstone-tales:adventure:v1`，原型会话进度不迁移为正式完成记录。

在站点地址后追加 `playground/` 即可进入；`#adventure`、`#space`、`#stickers`、`#maker` 可直接定位方案。各原型也有同名独立 HTML 页面。正式页面增加可见的 Playground 入口，四套原型独立于正式版手记数据。

| 方案 | 视觉 | 实际可体验流程 | 主要比较点 |
| --- | --- | --- | --- |
| A 宝石冒险岛 | 森林绿、暖黄、海蓝；原创岛屿地图与晶体角色 | 选地点 → 真实标本观察 → 问答与解释 → 发现印章 | 孩子是否能理解探索路线、自然地继续下一站 |
| B 星际研究站 | 深靛蓝、薄荷绿、橙色；星球与晶体宇航员 | 选择问题 → 收集三条线索 → 推断 → 研究档案 | 是否愿意先看证据再下判断，分步提示是否明确 |
| C 宝石贴纸册 | 奶油纸、珊瑚橘、彩色胶带、手绘宝石贴纸 | 自选宝石 → 选择观察词 → 小挑战 → 收下贴纸 | 是否能自主浏览并记住宝石的特点 |
| D 造物小工坊 | 暖黄、青绿、紫色；积木工具与纸张画布 | 观察真实标本纹样 → 选形状和配色 → 拼贴 → 作品角 / SVG 导出 | 是否能把观察转化为自己的表达，工具是否容易操作 |

四套均使用现有本地真实标本照片与来源，原创 SVG 角色、地图、星球和几何图章标为示意。它们不是照片鉴定工具；不安排刮划、研磨、敲击等实物操作。

## 选择与状态

- “我更喜欢这套”只记录选型，不把原型自动用于正式版；允许继续比较和清除选择。
- 选型使用独立的 `localStorage` 键 `gemstone-tales:playground-choice:v1`。浏览器不允许写入时明确提示仅在本次页面标记。
- 原型内部进度是本次页面状态。切换页面或刷新会重置；不会读写正式版的 `gemstone-tales:v1`。
- 工坊的示范拼图有明确标记，加入自己的图章后才能收藏或导出；用户标题在 SVG 和作品角中进行文本转义。
- 模态框支持 Escape 和关闭按钮；各原型有窄屏布局，动画尊重减少动态效果设置。工坊可用键盘 Enter 在画布中央放下图章。

## 网络与开源参考

延续 [开源调研](open-source-research.md) 中的做法：复用已核实许可的照片与事实数据，适龄界面用项目原生 HTML/CSS/SVG/JavaScript 实现，不引入额外前端依赖。四种界面是原创原型，没有复制第三方页面、角色或品牌资产。

本轮查阅 [NASA Space Place 的儿童游戏与活动入口](https://spaceplace.nasa.gov/menu/play/)，参考其把科学内容组织成探索、制作和问题任务的方式；查阅 [英国自然历史博物馆的岩石与矿物内容入口](https://www.nhm.ac.uk/discover/rocks-and-minerals.html)，维持从真实自然标本与故事切入的知识原则。上述来源用于交互与内容组织参考，并不代表其对本站的认证或背书。

## 验证

`npm run check` 包含原图鉴内容校验和 `scripts/validate-playground.mjs`。后者检查总览、四套 HTML、内联脚本语法、移动端 viewport 与本地静态资源存在性。浏览器另核查核心任务流程、模态框关闭、手机布局和原型状态隔离；自动检查不能替代儿童实际使用反馈。
